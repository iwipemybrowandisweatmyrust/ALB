# ALB
ALB stands for Automatic Lichess Bot,it is a script that connects to ollama using a lichess token. It forces the bot running to play moves every game you play whenever you start a game on lichess.

It is only for windows, it could work for mac or linux though.

HOW TO INSTALL
- Install the file
- Put it in documents
- Run the bot with ollama
- Make sure the account it is going to run on is a BOT account
- Make a api token,make sure it has everything checked
- Put the api in the api slot in the code,edit it using notepad
- Also edit the model to whatever you want
- Run the command in terminal [python C:\Users\Computer\Documents\ollama_chess.py]
- Select a game and watch it play!
